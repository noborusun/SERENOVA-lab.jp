# 哨戒班(しょうかいはん) - 巡航ミサイル型情報収集アプリ

Polymarket上の9つの予測市場を毎週火曜9:00(JST)に自動巡回し、
スクリーンショットと確率データを収集、週/月/3か月/6か月/年単位で
自動比較コメント付きレポートを生成する仕組みです。

## なぜ火曜朝9時か
今週、米国市場がどのような状況で始まったかを見て、日本市場への影響を
客観的に推測するため(月曜の米国市場の動きが出揃った直後を狙う)。

## 監視対象の9マーケット
1. 日経225(年末終値)
2. USD/JPY(年末終値)
3. WTI原油
4. ゴールド(GC)
5. S&P500
6. 2026年中間選挙(パワーバランス)
7. ホルムズ海峡交通
8. イラン封鎖解除
9. FRB利上げ

対象は `scripts/collect.js` 内の `TARGETS` 配列を編集すれば増減できます。

## SERENOVA-lab.jp リポジトリへの組み込み方

1. このフォルダの中身をそのまま `SERENOVA-lab.jp` リポジトリ直下にコピー
   - `.github/workflows/shokaihan-weekly.yml`
   - `scripts/collect.js`
   - `scripts/analyze.js`
   - `scripts/cleanup.js`
2. 既存の `weekly-screenshot.yml`(旧・単一ページ版)は役目が重複するため、削除して問題ありません
3. GitHubにpush
4. Actionsタブ →「Shokaihan Weekly Intelligence」→「Run workflow」で手動テスト

## 生成されるファイル

| パス | 内容 |
|---|---|
| `screenshots/YYYY-MM-DD/01_nikkei225.png` 〜 `09_fedhike.png` | その日撮影した9マーケットのスクリーンショット(3か月経過後は自動削除) |
| `data/history.json` | 全期間の収集データ(確率の生データ)。分析の元ネタ |
| `data/report_state.json` | 月次/四半期/半期/年次レポートを「いつ最後に出したか」の管理用(触らなくてOK) |
| `reports/YYYY-MM-DD_report.md` | その週生成されたレポート(noteにそのまま貼れるMarkdown形式) |
| `reports/latest.md` | 常に最新版を指す固定ファイル名 |

## レポートの中身
- 週次比較は毎回、月次・3か月・6か月・年次比較は該当する周期の最初の実行時にのみ、
  同じレポートの中に追加で出力されます
- 各マーケットについて「前回」「今回」「変化・コメント」を表形式で表示
- 5ポイント以上動いた場合は「大きな変化」、それ未満は「前回と同様の動き」と自動判定
- データが取得できないマーケット(イベント終了などで賞味期限切れの可能性)には注意マークが付きます

## 正直な制約(お伝えしておきたいこと)
Polymarketはマーケットごとに表示形式が異なる(Yes/No形式、複数選択肢形式など)ため、
**「代表確率」の自動抽出は完璧ではありません。** ページ内の「NN%」という表記を機械的に
拾っているだけなので、必ず週次でスクリーンショットも目視確認し、レポートの数字と
実際の画面を照らし合わせてから note・LP・動画に使ってください。数字の自動判定は
あくまで「見るべき候補を絞り込むための一次スクリーニング」として使うのが安全です。
